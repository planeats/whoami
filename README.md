# 나의 소개 홈페이지

GitHub Pages로 배포할 수 있는 기본 개인 홈페이지 템플릿입니다.

## 수정할 곳

- `index.html`의 `YOUR NAME`
- 이메일, GitHub, LinkedIn 링크
- 소개 문장
- 프로젝트 카드 내용
- `styles.css`의 색상 변수

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 올립니다.
3. 저장소의 `Settings` -> `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, folder를 `/root`로 선택하고 저장합니다.
6. 잠시 후 `https://사용자이름.github.io/저장소이름/` 주소로 접속할 수 있습니다.

이번 사이트는 `planeats/whoami` 저장소 기준으로 배포하면 아래 주소에서 볼 수 있습니다.

```text
https://planeats.github.io/whoami/
```

사용자 이름과 같은 이름의 저장소를 만들면 `https://사용자이름.github.io/` 주소를 사용할 수 있습니다.
